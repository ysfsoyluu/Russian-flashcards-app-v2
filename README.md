# Shuffle & Learn 🇷🇺

An interactive Russian vocabulary web app for learners at every level — A1 beginner through C2 advanced.

## Features

- **1,406 words** across A1–C2 levels
- **Flashcards** — tap to flip, swipe to mark as Learned, Revisit, or Favourite
- **Russian Wordle** — guess a 5-letter Russian word in 6 tries
- **Matching Game** — race the clock to pair Russian words with their translations
- **Search** — instantly look up any word with meaning and example sentences
- **Progress tracking** — view your Learned, Revisit, and Favourites lists
- **Level filter** — study by level: A1 · A2 · B1 · B2 · C1 · C2 · All
- Works on mobile and desktop — no install needed

## How to Use

Open the app in any browser — no login or installation required.

**Swipe right** / tap ✓ Learned — you know this word  
**Swipe left** / tap ↺ Revisit — add it to your revisit pile  
**Swipe up** / tap ★ Favourite — save to My Lists  
**Tap a card** — flip to see the translation and example sentence
